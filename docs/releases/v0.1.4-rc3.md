## English

Third release candidate for v0.1.4. Changes below are compared with **v0.1.4-rc2**.

### New features

- Added a **Windows x64 portable package** with `gitra.exe`, a double-click launcher, and English/Chinese instructions. Install Git for Windows first; Go and WSL are not required.
- Windows now supports repository operations with native file locking and Git Credential Manager. Browser authorization uses the optional GitHub CLI (`gh`); token login works without it.
- Release downloads now include one macOS package, one Windows x64 package, and shared SHA-256 checksums.

### Fixes and verification

- Replaced the unsupported Windows file-lock implementation with native cross-process locking, including wait cancellation and release after callback errors.
- Normalized Git paths on Windows and quoted SSH key and file-based helper paths correctly, including spaces and Chinese characters.
- Added Windows CI checks for two-account credential isolation, initialization, binding, first upload to a local remote, and unbinding. Extracted-package checks cover the version, launcher paths, missing Git, and command failures.
- Full Linux/macOS Go regression and macOS bundle smoke checks also passed before tagging.

### Downloads and testing

- **Windows:** download `Gitra-Windows-x64.zip`, extract the entire archive, and double-click `Gitra.cmd`. Install Git for Windows with its default Git Credential Manager and command-line PATH options. Install `gh` if you want browser authorization.
- **macOS:** download `Gitra-macOS.zip`, extract it, and open `Gitra.app`. It supports Apple Silicon and Intel Macs. If the first launch is blocked, use System Settings → Privacy & Security → Open Anyway.
- **`checksums.txt`:** SHA-256 checksums for both application archives. GitHub's Source code archives contain source files.

Please try Windows browser/token login, keyboard navigation, and binding a real project folder. Browser authorization and interactive desktop rendering still need manual testing. The Windows package targets x64 and opens a terminal UI with Chinese labels. Initialization does not stage, commit, or upload files; create a local commit before the first upload. Passphrase-protected SSH keys require an SSH agent.

This is a **Pre-release** and does not replace the latest stable release.

## 简体中文

这是 v0.1.4 的第三个候选版本，以下更新以 **v0.1.4-rc2** 为基线。

### 新增功能

- 增加 **Windows x64 便携包**，内含 `gitra.exe`、双击启动脚本和中英文说明。先安装 Git for Windows 即可，不需要 Go 或 WSL。
- Windows 支持原生文件锁和 Git Credential Manager。浏览器授权需要可选的 GitHub CLI（`gh`）；直接粘贴访问码不需要 `gh`。
- 发布下载包含一个 macOS 应用包、一个 Windows x64 便携包，以及共用的 SHA-256 校验文件。

### 修复与验证

- 将 Windows 原先不支持的文件锁改为原生跨进程锁，支持取消等待及执行失败后的释放。
- 规范化 Windows 的 Git 路径，正确引用 SSH 密钥和文件凭据 helper 路径，支持空格与中文。
- 增加 Windows CI，验证两个账号的凭据隔离、初始化、绑定、向本地远端首次上传和解绑；解压后的包验证版本号、启动路径、Git 缺失提示及命令失败提示。
- 打标签前，全量 Linux/macOS Go 回归和 macOS 应用包冒烟也已通过。

### 下载与试用

- **Windows：** 下载 `Gitra-Windows-x64.zip`，完整解压后双击 `Gitra.cmd`。安装 Git for Windows 时保留默认的 Git Credential Manager 和命令行 PATH 选项；需要浏览器授权时再安装 `gh`。
- **macOS：** 下载 `Gitra-macOS.zip`，解压后打开 `Gitra.app`，同时支持 Apple Silicon 与 Intel。若首次启动被拦截，在“系统设置 → 隐私与安全性”选择“仍要打开”。
- **`checksums.txt`：** 两个应用压缩包的 SHA-256 校验值。GitHub 自动附带的 Source code 为源码包。

建议实际试用 Windows 浏览器/访问码登录、键盘操作和真实项目文件夹绑定。浏览器授权和桌面交互显示仍需人工确认。当前 Windows 包为 x64 终端应用，界面使用中文标签。初始化不会自动暂存、提交或上传文件；首次上传前需要创建本地提交。带口令的 SSH 密钥需要 SSH agent。

本版本标记为 **Pre-release（预发布）**，不替换最新正式版本。
