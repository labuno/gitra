## English

Second release candidate for v0.1.4. Changes below are compared with **v0.1.4-rc1**.

### Changes and fixes

- Simplified downloads to **one universal macOS application ZIP and its checksum file**. The app supports both Apple Silicon and Intel Macs.
- Added version-specific, bilingual release notes covering features, fixes, usage limits, and downloads.
- The release workflow now stops with a clear error if the version's release notes are missing or empty.
- Added workflow tests for release notes, RC marking, duplicate releases, and the two-file download contract.

### Features to test

- Select an ordinary project folder to initialize a `main` branch, associate a remote, and bind the selected account.
- Press `S` in the folder picker, restart gitra, and verify that the saved starting directory is used.
- Confirm that binding an existing repository preserves its history and remote address.

These application features were introduced in RC1 and remain available in RC2. Initialization does not stage, commit, or upload files. Create a local commit before the first upload. Automatic initialization applies to single-folder binding in the terminal UI; CLI and bulk binding require existing Git repositories. Online remote creation uses HTTPS accounts; SSH accounts associate existing SSH addresses. The terminal UI currently uses Chinese labels.

### Downloads

- **`Gitra-macOS.zip`**: extract the archive and open `Gitra.app`. If macOS blocks the first launch, use System Settings → Privacy & Security → Open Anyway, then launch again.
- **`checksums.txt`**: SHA-256 checksum for the application ZIP.
- GitHub's two **Source code** archives contain source files and are not installers. Separate CLI archives are no longer generated; the CLI can be built from source.

This is a **Pre-release** for testing and does not replace the latest stable release.

## 简体中文

这是 v0.1.4 的第二个候选版本，以下更新以 **v0.1.4-rc1** 为基线。

### 变更与修复

- 下载产物精简为 **一个 macOS 通用应用包和一个校验文件**，同时支持 Apple Silicon 与 Intel Mac。
- 增加按版本维护的中英发布说明，包含功能、修复、使用限制和下载方式。
- 对应版本说明缺失或为空时，发布工作流会明确报错并停止。
- 增加发布说明、RC 标记、重复发布和两个下载文件约定的工作流测试。

### 本次建议验证

- 选择普通项目文件夹，初始化 `main` 分支、关联远端并绑定所选帐号。
- 在文件夹选择器中按 `S`，重启 gitra 后确认仍从保存的起始目录打开。
- 绑定已有仓库后，确认历史和远端地址保持不变。

上述应用功能在 RC1 中加入，RC2 继续保留。初始化不会自动暂存、提交或上传文件，首次上传前需要本地提交。自动初始化适用于 TUI 单文件夹绑定；CLI 与批量绑定仍要求已有 Git 仓库。在线创建远端使用 HTTPS 帐号，SSH 帐号关联已有 SSH 地址。当前终端界面使用中文标签。

### 下载说明

- **`Gitra-macOS.zip`：** 解压后打开 `Gitra.app`；若首次启动被拦截，在“系统设置 → 隐私与安全性”选择“仍要打开”，然后再次启动。
- **`checksums.txt`：** 应用包的 SHA-256 校验值。
- GitHub 自动附带的两个 **Source code** 是源码包，不是安装包。后续不再生成独立 CLI 下载包，需要命令行版时可从源码构建。

本版本标记为 **Pre-release（预发布）**，用于测试，不替换最新正式版本。
