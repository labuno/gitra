## English

Release candidate for the next stable version. Changes below are compared with **v0.1.2**.

### New features

- **Bind ordinary project folders:** selecting a folder initializes a Git repository with a `main` branch, then guides you through associating an existing remote or creating a repository through an HTTPS account.
- **Save your starting directory:** press `S` in the folder picker to save the current directory. The setting applies across accounts and app restarts.
- **Bilingual documentation:** the default README is in English, with a separate Simplified Chinese version and language links.

### Fixes and release changes

- Fixed the binding flow rejecting ordinary folders simply because they had no `.git` directory.
- Fixed a repository setup test relying on a developer's Git identity settings, which caused Linux CI and the v0.1.3 release workflow to fail.
- RC releases are now marked as **Pre-release** and do not replace the latest stable release.

### Usage notes

- Initialization does not stage, commit, or upload your files. Create a local commit before the first upload.
- Existing repository history and remote URLs are preserved.
- Automatic initialization is available for single-folder binding in the terminal UI; CLI and bulk binding still require existing Git repositories.
- SSH accounts associate existing SSH remote addresses; online repository creation uses HTTPS accounts. The terminal UI currently uses Chinese labels.

### Downloads

- **macOS desktop:** download `Gitra-macOS.zip`, extract it, and open `Gitra.app`. The application supports both Apple Silicon and Intel Macs.
- **Command line:** choose the ZIP matching your operating system and architecture. `arm64` is for ARM processors; `amd64` is for Intel/AMD x86-64 processors. Windows archives include `.exe` in their names.
- **Verify downloads:** `checksums.txt` contains SHA-256 checksums for the uploaded ZIP files.
- GitHub's **Source code** archives contain source files and are not installers.

## 简体中文

这是下一正式版本的候选版。以下更新以 **v0.1.2** 为基线。

### 新增功能

- **普通文件夹直接绑定：** 选择项目文件夹后初始化 Git 的 `main` 分支，再引导关联已有远端，或通过 HTTPS 帐号创建仓库。
- **保存起始目录：** 在文件夹选择器中按 `S` 保存当前目录，跨帐号和应用重启生效。
- **中英文文档：** 默认 README 显示英文，另提供简体中文版和语言切换链接。

### 问题修复与发布改进

- 修复普通文件夹没有 `.git` 时被绑定流程直接拒绝的问题。
- 修复仓库初始化测试依赖开发者本机 Git 身份配置的问题；该问题曾导致 Linux CI 和 v0.1.3 发布失败。
- RC 自动标记为 **Pre-release（预发布）**，不替换最新正式版本。

### 使用说明与限制

- 初始化不会自动暂存、提交或上传文件，首次上传前需先创建本地提交。
- 已有仓库的提交历史和远端地址保持不变。
- 自动初始化适用于终端界面的单文件夹绑定；CLI 与批量绑定仍要求已有 Git 仓库。
- SSH 帐号关联已有 SSH 地址；在线创建仓库使用 HTTPS 帐号。当前终端操作界面使用中文。

### 下载说明

- **macOS 桌面版：** 下载 `Gitra-macOS.zip`，解压后打开 `Gitra.app`，同时支持 Apple Silicon 与 Intel Mac。
- **命令行版：** 选择对应操作系统与架构的 ZIP；`arm64` 对应 ARM，`amd64` 对应 Intel/AMD x86-64，Windows 文件名额外包含 `.exe`。
- **校验文件：** `checksums.txt` 提供上传 ZIP 的 SHA-256 校验值。
- GitHub 自动生成的 **Source code** 是源码包，不是安装包。
